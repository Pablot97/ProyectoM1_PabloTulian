# Documentación del uso de IA

Durante el desarrollo del proyecto se utilizó inteligencia artificial como herramienta de apoyo para resolver dudas, comprender conceptos y mejorar el proyecto.


## Prompt 1

Cómo publico mi proyecto utilizando GitHub Pages?

### Resultado

Se siguieron las indicaciones para publicar la aplicación mediante GitHub Pages.

## Prompt 2

Cómo puedo agregar un botón para copiar el código de color?

### Resultado

Se implementó un botón que permite copiar el código del color utilizando la función `navigator.clipboard.writeText()`.

## Prompt 3

Cómo puedo hacer que el botón Copiar aparezca cuando paso el puntero sobre el color?

### Resultado

Se utilizó CSS para ocultar inicialmente el botón y mostrarlo mediante el selector `:hover`.
